# 桌面前端说明

本版根据用户提供的设置界面参考图，采用居中标题、黑蓝渐变、大幅手柄线稿、分页面编辑和底部固定操作。仍使用原有 .NET 10 / WPF 引擎与全局配置，不依赖浏览器。

## 操作流程

1. 在首页查看已保存配置数量与当前名称，选择全局配置；“查看已保存配置”打开列表。“新建配置”创建独立配置；“保存配置”更新当前配置。重新启动后恢复上次保存时选择的配置。
2. 进入“自定义按键配置”，点选图上的 LT/RT 或其他按钮，也可点击“添加 / 修改键位”。在弹窗选择实体输入键、虚拟输出键、可选的第二输出、Shift 切换键与所属层，点击“确认映射”。相同输入、相同层的已有规则会被替换；与连发占用同一键时给出冲突提示。
3. 弹窗中的更改先暂存；取消不会改变配置。冲突会显示提示并保留原来的映射。
4. “查看映射规则”可查看和逐条移除规则。未映射按钮保持原始输出。
5. “单键连发”页同时设置触发键与输出键，调节 50–1000 毫秒间隔；关闭按钮可同时清空两项。
6. 到“设备与运行”连接手柄，软件每 2 秒检查一次，也可手动刷新。DualSense HID 优先自动选中并显示 PlayStation 输入按钮名；XInput 显示 Xbox 输入按钮名。输出始终为虚拟 Xbox 360。用户手动选择的设备会保留，直到设备断开。当前配置全局生效，切换前台窗口后连发需要重新松开并按下触发键。
7. 点击底部“保存配置”保存全部配置，再点击按键页的“启用映射”或设备页的“启用 / 恢复映射”。保存不等于启用；修改配置会停止原有输出。底部始终显示启用状态并保留立即停止按钮。

按键白色描边代表选中的映射输入；蓝色背景来自引擎报告的真实按下状态，仅启用后更新。手柄图为通用示意，背键须设备报告支持。未映射的 LT/RT 保持模拟透传；作为映射输入时按约半程阈值转为单个按键事件，作为虚拟输出时为全按下。映射仅修改虚拟手柄；若目标游戏同时读取实体手柄，原按键仍可能生效。此版本未新增摇杆灵敏度、死区、震动或自适应扳机功能。

按住窗口顶部标题或两侧空白区域可拖动窗口；返回和设备说明按钮保持正常点击。

快捷键：Ctrl+S 保存，F5 刷新，Esc 立即停止（仅本窗口内）。退出时如有未保存修改，会提示保存、放弃或取消退出。

## 实现入口

- `UI/MainWindow.xaml`：首页、按键、连发、配置和设备页，以及两个弹窗。
- `App.xaml`：颜色、圆角按钮、卡片、状态样式。
- `UI/ButtonLabelConverter.cs`：页面显隐、中文按键名称和实时状态匹配。
- `ViewModels/MainViewModel.cs`：导航、弹窗暂存与提交、配置操作和校验。
- `Assets/controller-outline.png`：本次生成的无品牌通用手柄线稿。原始参考截图未打包为应用素材。

路径相对于 `src/ControllerMapper.Desktop`。

## 无硬件检查

从仓库根目录运行：

```powershell
dotnet run --project tests/ControllerMapper.FrontendChecks/FrontendQa.csproj -c Release
```

检查使用独立配置目录及模拟输入输出，不连接虚拟驱动。覆盖旧配置迁移、导航、可见按钮打开编辑器并确认普通映射、扳机映射与模拟透传、弹窗取消、映射替换与冲突回滚、Shift 依赖、连发校验、保存后立即可见、重新打开后恢复选中项、Xbox / DualSense 标签切换和设备断开回退。WPF 实际渲染图、绑定日志与结果位于 `artifacts/frontend-v2-qa`。

界面渲染与配置检查不替代真实手柄、驱动和游戏验收。
